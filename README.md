# Linear Regression — Coursework

University machine-learning exercise comparing linear-regression behavior at different learning rates.

## Files

- `main.ipynb`: experiment notebook.
- `ex1data1.txt`: experiment input data.
- `Learning Rate 0.01/`, `Learning Rate 0.1/` and `Learning Rate 1/`: saved experiment artifacts.
- `HW1.pdf`: assignment material.

Open the notebook with Jupyter and review its data paths and imports before running the cells. This repository preserves an academic experiment; it is not a production forecasting service.
